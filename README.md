# claude-mods

Mods for [Claude Code](https://claude.com/claude-code): plugins that change its own interface.

| Mod | Folder | What it does |
| --- | --- | --- |
| `radio` | [`radio-fm/`](radio-fm) | Internet radio in a pane: radio-browser.info directories and your own stations, search, favorites |

## Install

In a Claude Code terminal session:

```
/plugin install radio --marketplace gsfitis/claude-mods
```

Answer `y` to add the marketplace, then pick a scope (user scope loads it in every session).
